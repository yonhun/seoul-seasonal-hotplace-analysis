# 🚇 계절을 바꾸는 도시의 발걸음

### 대중교통과 유동인구 기반 서울시 핫플레이스 변화 분석

> **"도시 공간은 고정된 것이 아니다. 계절과 날씨에 따라 서울의 핫플레이스는 끊임없이 재편된다."**

봄이면 벚꽃이 흩날리는 여의나루, 여름이면 계곡을 찾아 떠나는 가평·청평, 가을이면 단풍 명소 한양대·대공원, 겨울이면 스키장 인근 백양리 — 서울 시민의 발걸음은 사계절에 따라 전혀 다른 도시를 그려냅니다.

본 프로젝트는 **521개 지하철역 × 1,096일 × 약 57만 건**의 승하차 데이터와 기상 데이터를 결합하여, 계절·날씨·요일 조건에 따른 유동인구 중심지의 공간적 재편을 정량적으로 분석합니다.

## 🔍 주요 발견 (Key Insights)

**1. 계절마다 서울의 "핫플레이스"는 완전히 달라진다**

- **봄**: 여의나루, 응봉, 자양(뚝섬한강공원) 등 한강 인근 역의 유입이 급증 → 벚꽃·야외 산책 수요 반영
- **여름**: 대성리, 가평, 청평, 강촌 등 외곽 휴양지와 인천공항 터미널 유입 증가 → 피서·여행 수요
- **가을**: 한양대, 대공원(서울대공원), 운길산 등 단풍 명소 집중 → 계절 경관 + 문화행사
- **겨울**: 백양리(엘리시안강촌 스키장), 명동, 성수 등 → 스키·실내쇼핑·문화활동

**2. 날씨는 "결정적" 요인이 아니라 "보조적" 요인이다**

날씨 유형별 회귀분석 결과, 대부분 역에서 R² < 0.1로 나타나 날씨만으로는 유입량 변화를 설명하기 어렵습니다. 시민의 이동은 날씨보다 **계절 자체의 문화적·사회적 맥락**(벚꽃, 휴가, 단풍, 연말)에 더 큰 영향을 받습니다.

**3. "진짜 핫플레이스"는 주말 의존도로 구분할 수 있다**

선형회귀분석에서 휴일 여부(0=평일, 1=주말)에 대한 R² ≥ 0.9인 역들은, 평균 유입량이 크지 않더라도 **주말에만 선택적으로 방문되는 여가 중심지**임을 의미합니다. 이를 통해 구조적 혼잡지(강남, 서울역 등)와 계절형 핫플레이스를 정량적으로 분리할 수 있었습니다.

**4. 날씨에 따른 흥미로운 행동 패턴**

- 맑은 여름날 → 나무 그늘이 풍부한 대공원·월드컵경기장 선호 / 흐린 여름날 → 그늘 없는 여의나루 유입 증가
- 비 오는 날 → 봉은사(코엑스몰 인접) 유입 증가 = 실내활동 수요
- 봄철 적설·대설 → 백양리(스키장) + 광화문(눈 오는 감성 명소) 유입 집중

## ⚙️ 데이터 처리 과정

3년치 월별 CSV 36개 파일을 통합하는 과정에서 다양한 데이터 품질 이슈를 체계적으로 해결했습니다:

- **칼럼 밀림 문제**: 일부 월별 파일에서 데이터가 1열씩 밀려있는 현상 → 등록일자 기반 복원
- **누락 역 32개 분류 및 처리**: 신규 개업(10개역, 개업일 이후만 분석), 조사 누락(12개역, 분석 제외), 역명 변경(4건, 최신명 통합)
- **동일 역 다중 노선 통합**: 같은 역명의 서로 다른 노선 승하차 데이터를 합산
- **빠진 일자 보정**: 2023-06-26, 2024-07-05 → 전주 동일 요일 데이터 삽입
- **계절 구분**: 천문학적 기준이 아닌 **기상학적 기준** 적용 (평균 기온 5일 연속 유지 기준, KMA 정의)
- **휴일·방학 분류**: `holidays` 라이브러리 + `datetime` 활용, 여름방학(7~8월)·겨울방학(1~2월) 구분

## 📐 분석 방법론

### 1. 기준선 분석 (Baseline Analysis)

3개년 전체 평균 유입량을 기준값으로 설정하고, 계절별 평균과의 **상대 유입률**을 계산합니다.

```
상대 유입 증가율(%) = (계절별 평균 - 전체 평균) / 전체 평균 × 100
```

이를 통해 절대 유입량이 항상 높은 **구조적 혼잡지**(강남, 서울역, 잠실 등)와, 특정 계절에만 유입이 상승하는 **계절형 핫플레이스**를 분리합니다.

### 2. 시간 조건 분리 분석

전체 / 평일 / 주말·공휴일 / 방학 기간 데이터를 각각 분리하여 분석합니다. 평일 데이터는 통근·통학 중심의 고정 패턴을, 주말 데이터는 시민의 자발적 여가·소비 선택을 반영합니다.

### 3. 선형회귀분석 (R² 기반 주말 의존도 분석)

각 역에 대해 종속변수(일별 유입량)와 독립변수(휴일 여부: 0 또는 1)로 단순 선형회귀를 수행합니다. R² ≥ 0.9인 역은 유입량의 90% 이상이 휴일 여부로 설명되므로, **주말에만 선택적으로 방문되는 여가 중심지**로 해석할 수 있습니다.

### 4. 계절 × 날씨 × 주말 복합 분석

주말·공휴일 데이터를 계절별로 분류한 뒤, 날씨 유형(8종)별 상대 유입 증가율 상위 3개 역을 도출합니다. 이를 통해 "봄 + 맑음 + 주말"에는 어디가 핫플레이스인지를 구체적으로 식별합니다.

## ⚠️ 한계점 & 향후 과제

**데이터 범위의 한계**
- 지하철 데이터만 활용 (전체 대중교통 이용의 약 32%). 버스·택시·통신사 기반 데이터와의 멀티모달 통합이 향후 과제입니다.
- 하차량만을 유입 지표로 사용하여 승차·환승 수요는 미반영. 다만, "어디를 찾아가는가"라는 목적지 식별에는 하차 데이터가 적합합니다.

**기상 데이터의 공간 대표성**
- 서울 전역을 종로구 관측소 단일 지점으로 대표. 지역 간 미세한 날씨 차이(예: 한강변 vs 북한산)를 반영하지 못합니다.

**시간 구분의 단순화**
- 평일/주말 이분법으로, 금요일 저녁(실질적 주말)이나 일요일 귀가 수요 등의 미세한 차이를 구분하지 못했습니다.

**향후 확장 방향**
- 멀티모달 교통 데이터 통합 (버스, 택시, 통신사 유동인구)
- 실시간 분석 시스템 구축
- 소상공인 매출 데이터와의 연계 분석 → 상권 활성화 예측
